PATCH: Excel/PDF Produk & Laporan Keuangan

Fitur yang ditambahkan:
1. Export seluruh data produk ke Excel (.xlsx) dan PDF.
2. Import produk dari Excel (.xlsx), CSV, dan PDF hasil export KasirPro.
3. Mode import tambah baru saja atau tambah + perbarui produk lama.
4. Preview import membedakan produk baru, produk diperbarui, dan data error.
5. Sinkronisasi stok cabang dan pencatatan riwayat stok saat import/update massal.
6. Halaman laporan keuangan dengan filter periode dan jenis transaksi.
7. Export laporan keuangan ke Excel (.xlsx) dan PDF.
8. Ringkasan laporan mencakup pemasukan, pengeluaran, saldo, hutang, piutang, dan jumlah transaksi.

Catatan pemasangan:
- Tidak ada query SQL tambahan.
- Salin seluruh file patch sesuai struktur folder proyek.
- PDF yang dapat diimport kembali hanyalah PDF data produk hasil export KasirPro, karena PDF tersebut menyimpan data produk terstruktur secara aman.
- File Excel lama .xls tidak didukung; gunakan format .xlsx atau CSV.
