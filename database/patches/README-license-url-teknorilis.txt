License URL Configured

URL server lisensi sudah diset default ke:
https://teknorilis.tech/license-api

Yang disesuaikan:
- public/license-setup.php
- public/admin/settings/index.php
- database/patches/patch-license-url-teknorilis.sql

Catatan:
Kalau database sudah punya setting license_api_url lama, halaman Pengaturan tetap bisa menggantinya.
Jika ingin paksa update database, jalankan patch SQL di atas.
